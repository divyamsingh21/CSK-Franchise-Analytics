\# CSK Franchise Analytics



An end-to-end data analytics project focused on exploring and analyzing the performance of the Chennai Super Kings (CSK) franchise in the Indian Premier League (IPL).



The project uses Python-based data analysis and an interactive Power BI dashboard to transform cricket data into meaningful performance insights.

\## Project Objectives



\- Analyze CSK's overall IPL performance.

\- Explore batting and bowling contributions.

\- Examine season-wise team performance.

\- Analyze player consistency and contributions.

\- Explore toss decisions, match outcomes and venue performance.

\- Present analytical findings through an interactive Power BI dashboard.



\## Tools \& Technologies



\- \*\*Python\*\* – Data analysis and processing

\- \*\*Pandas\*\* – Data manipulation

\- \*\*SQL / DuckDB\*\* – Data querying and analysis

\- \*\*Jupyter Notebook\*\* – Exploratory data analysis

\- \*\*Power BI\*\* – Interactive dashboard development

\- \*\*CSV / Excel\*\* – Analytical datasets and outputs

\## Analytical Areas



The project includes analysis of:



\- Batting performance and strike rates

\- Bowling performance and economy rates

\- Player consistency and contributions

\- Season-wise performance

\- Scoring and boundary patterns

\- Powerplay, middle-over and death-over analysis

\- Toss and chasing analysis

\- Venue and opponent analysis



\## How to Explore the Project



1\. Browse the Jupyter Notebook in the `notebooks/` directory.

2\. Explore the CSV and Excel analytical outputs in `outputs/`.

3\. Download and open the `.pbix` file in Microsoft Power BI Desktop.

4\. Explore the three dashboard pages to understand the analysis.



\*\*Note:\*\* The Power BI report requires Power BI Desktop to open and interact with the `.pbix` file.
